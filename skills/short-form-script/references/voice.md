# Voice: the user's own scripts

The only voice sample for `short-form-script`. Every script here is the user's version, as written: never Claude's draft, never the transcript of a recorded take, never a reference clip. The user decides what goes in; add a script only when they say so.

Read it for register, not as a template: sentence length, tone, openers, asides, how a CTA is phrased. Do not copy hooks, loops or claims.

## Phrases that are voice

Keep these even when `humanizer` would flag them.

- "Funziona così." before the mechanism.
- "Il tool si chiama X" / "Il progetto si chiama X".
- Rhetorical openers: "E se ti dicessi che…", "Se ti chiedessi: …? Ovviamente …".
- The creator as guide, in the first person: "ci ho pensato io", "Ho appena rilasciato", "ci ho connesso".
- Colloquial asides: "Belli gli articoli scientifici eh, ma sono una palla da leggere", "Ciliegina sulla torta", "ha pensato bene di".
- "Ma c'è un problema" / "Ma non preoccuparti", two *ma* in a row.
- "Commenta X e ti mando il link." / "Se commenti X ti mando la guida e la repo."
- "Ma non finisce qui." and "E ora viene la parte che fa la differenza." appear in two scripts that performed well. The skill still counts them as empty rehooks (*Body and rehook*). Do not write them yourself; leave them where the user writes them.
